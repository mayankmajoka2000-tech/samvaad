An interpreter for two people who share no language. In the Windows app, every model runs on the Snapdragon NPU with no internet. This browser preview replays a recorded session and runs the numbers-and-names guard live. Source code: github.com/mayankmajoka2000-tech/samvaad.

On-device pipeline
  1. Capture CPU
  2. Gate CPU
  3. Recognise NPU
  4. Translate NPU
  5. Guard CPU
  6. Speak NPU
